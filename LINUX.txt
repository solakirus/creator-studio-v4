Creator Studio v4 on Linux (Mint)
=================================

It is the same desktop app as on Windows: Library, Templates, the grabber,
the NAS Shot Library copy, sync with nastime.

INSTALL
   In the folder with the download, open a terminal and run:
      sudo apt install ./CreatorStudio4-4.0.0.deb
   It shows up in the Mint menu as "Creator Studio v4".
   (The AppImage works too, no install: chmod +x it and double-click.)

SYNC
   Settings > Data > Sync with your server:  http://192.168.4.23:8787
   and your SYNC_TOKEN. Pick "Use the server's" so this computer starts with
   what the others have.

THE GRABBER (yt-dlp + ffmpeg)
   In a terminal:   sudo apt install ffmpeg pipx && pipx install yt-dlp
   then Library > Add & grab > Check again.

THE SHOT LIBRARY ON THE NAS
   Mount the NAS share (Files > Other Locations > smb://192.168.4.23), then
   Library > Folders > Choose a folder... and pick it. "Keep a copy..." works
   the same as on Windows.

NEW VERSIONS
   Unzip the update over the project folder, then run  ./build-linux.sh  in it.
   It builds the app, offers to install it (asks your password), then offers
   to update the web app on nastime too. Your data stays: it lives in
   ~/.config, not in the app.

THE WEB APP ON NASTIME (the iPad, any browser)
   ./publish-nas.sh  builds it and copies it to the NAS. The first time it asks
   where the NAS folder is - either the share opened in Files
   (Other Locations > Connect to Server > smb://192.168.4.23/creator-studio-v4,
   then drag that folder into the terminal), or over SSH:
      you@192.168.4.23:/DATA/AppData/Projects/creator-studio-v4
   After that it remembers. Browsers on the NAS address pick the new version up
   the next time they open.
