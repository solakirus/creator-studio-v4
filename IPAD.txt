Creator Studio v4 on the iPad - served from nastime
===================================================

The iPad opens the web app from your NAS. Sync Hub is on the same address,
so the iPad syncs with the phone and the laptop like they do.

ONE-TIME SETUP ON THE NAS (about 15 minutes)

1. Make the folder.  In CasaOS Files, under AppData/Projects, make a folder
   called creator-studio-v4. Turn on sharing for it (the share icon), so
   Windows can reach it as  \\192.168.4.23\creator-studio-v4

2. Put the app in it.  On the laptop, run  publish-nas.bat  in this folder.
   The first time it asks for the folder - type the address from step 1.
   It builds the app and copies www\ and the Caddyfile across.
   (No share? Upload creator-studio-v4-web.zip with CasaOS Files instead and
   extract it inside creator-studio-v4 - same result.)

3. Start the server.  CasaOS > App Store > Custom Install > Import, and paste
   the contents of  nas\docker-compose.yml . Install.
   Test it on the laptop:  http://192.168.4.23:8795   - the app opens.

4. HTTPS, so the iPad can install it properly.  Safari only lets a web app
   work offline and stay installed from an https address. Tailscale gives you
   one with a real certificate:
     - Tailscale admin console > DNS: turn on MagicDNS and HTTPS Certificates.
     - On nastime (CasaOS terminal or SSH):
         curl -fsSL https://tailscale.com/install.sh | sh      (if not installed)
         sudo tailscale up
         sudo tailscale serve --bg 8795
     - It prints the address, like  https://nastime.tail1234.ts.net

ON THE IPAD

5. Install the Tailscale app and sign in (same account).
6. Open the https address from step 4 in SAFARI.
7. Share > Add to Home Screen > Add. Always open it from that icon -
   Safari wipes an ordinary website's data after 7 unused days; a home-screen
   app is kept.
8. Settings > Data > Sync with your server. The address is already filled in
   (the app's own address). Enter your SYNC_TOKEN > Connect. A new iPad
   takes everything the phone and laptop have; if it asks, pick
   "Use the server's".

AFTER THAT

   To update the iPad: run publish-nas.bat on the laptop. The iPad picks it
   up the next time it opens with the NAS in reach.

   Use ONE address on the iPad. http://192.168.4.23:8795 and the https one are
   two different apps to Safari, each with its own data. (The http one works
   at home for a quick look, but can't work offline.)

WHAT IS AND IS NOT THERE

   Everything except the Android-only pieces (notifications, home-screen
   widgets, share-into-the-app) and the laptop-only Library and Templates
   (the iPad gets Starred, like the phone). The Apple Pencil works in the
   paper planner.
