Creator Studio v4
=================

A NEW APP. It installs BESIDE Creator Studio 3 and v2 and never touches them:
its own app id (com.solakirus.creatorstudio4), its own database, its own
space on Sync Hub, its own update site, its own cs4:// links. You start fresh.


WHERE TO PUT IT
  Extract the zip into  C:\Users\Khale\Projects\
  so you end up with:   C:\Users\Khale\Projects\creator-studio-v4\

  It must sit NEXT TO creator-studio-v2 only if you ever delete its android\
  folder (build.bat would then copy v2's once). The zip already has one.


BUILD IT (laptop and phone)
  Double-click  build.bat  inside that folder.
    Windows app?  Y  -> dist\  has the installer and a portable exe
    Android APK?  Y  -> dist\Creator Studio v4.apk
  Send the APK to the phone and install it. It shows up as "Creator Studio v4"
  with the new clapper logo, next to your old app.

  The first run takes a few minutes (npm install).


CONNECT SYNC (laptop first, then phone)
  Same Sync Hub on nastime as before — nothing to install on the server.
  v4 keeps its data in its own space there ("creator-studio-4"), apart from CS3.
    Laptop:  Settings -> Sync -> your server address and token -> Connect.
             v4's space starts empty, so the laptop sends everything up.
    Phone:   Settings -> Sync -> the same address and token -> Connect.
             It takes the laptop's data. If it asks, choose
             "Use the server's — replace this device".
  (In the OLD app: Settings -> Sync -> "Pause on this device", so you only
  ever plan in one.)


HOW THE SHOT LIBRARY GETS TO THE PHONE (it doesn't — only what you use)
  On the laptop, Content -> Library and Templates work as before.
  When a task or a video uses Library frames — a template put on a day,
  "New video" from a template, or a page on a task — the laptop copies just
  those GIFs, clips and stills into the task, a few seconds after you save.
  Sync carries them to the phone, where the task's shot page and steps show
  them, GIFs moving. The phone has no Library or Templates section.

  They clear themselves:
    - 21 days after the task's date (if no live video still uses them)
    - 21 days after a video is marked Published
    - a day after the task is deleted
  The Library on the laptop is never touched — only these copies.

  One limit: a single file over 30 MB doesn't travel (Sync sends one at a
  time). Trim long clips or use a GIF.


HABITS
  Year in dots is in: the Habits strip on Today, "Year in dots ›" for the
  grid, "+ Habit" to add one. Habits sync to the phone like everything else.


THE LOGO
  Three are in branding\ (see logo-options.png). Clapper Bolt is installed.
  To switch:   node scripts\use-logo.js rec4        (or viewfinder, clapbolt)
  then build.bat again.


IPAD AND AUTO-UPDATES (optional, later)
  The iPad version and the phone/Windows self-updates come from GitHub Pages,
  from a NEW repo:  github.com/solakirus/creator-studio-v4
  Follow  PUT IT ON GITHUB.txt  from STEP 2. Until then everything works; the
  apps just update when you run build.bat instead of by themselves.

  Never run update.bat in the old creator-studio-3 folder expecting it to
  reach v4 — they are separate apps with separate sites now.
